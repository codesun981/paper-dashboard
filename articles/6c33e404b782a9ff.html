用《 High Output Management 》的早餐工厂讲怎么管 agent 《 Loops You Can Trust 》

我觉得有用的几点：

  • 验证是 "限制步骤"。agent 没法确认自己做对了，循环跑得越多，要你返工的 slop 就越多。
  • 每个环节都能叫停整条线：分诊可以判定 "这不是 bug"，复现可以 "复现不出来"，修复可以说 "风险太大"。坏活在前面就挡住了，越往后纠正越贵。
  • poteto 把共用 UI 库迁到 StyleX ，PR 将近 40 万行，像素级对齐了，自己团队一用还是翻出 z-index 和优先级问题。后来改成 automation 每天只迁一个叶子组件，每个 PR 都附截图和视频。
  • 建议从零开始：不装插件，不写 AGENTS.md ，先看 agent 在哪出错。同样的错反复出现就写成 skill ，能写成 lint 规则或者改代码结构更好。
