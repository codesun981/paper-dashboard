Anthropic收紧Claude使用边界 禁止逆向工程复刻现有游戏

0 cnBeta.COM   2026-11-01 01:14:38

摘要：

近段时间以来，借助 AI 克隆游戏、逆向工程与反编译的做法愈发流行，一批游戏项目几乎在一夜之间涌现，形成了一种小规模的“家庭作坊式”产业。这些项目类型多样，既有引发争议的《堡垒之夜》与《辐射》克隆作品，也有玩家自制的游戏主机移植版本。

如今看来，Anthropic 似乎已经受够了负面舆论，也可能承受着来自游戏行业巨头的压力。有用户反映，Claude 不再愿意复刻游戏机制或重现现有游戏，相关情况由 Tom's Hardware 率先报道。

一名 X 平台用户指出了 Claude 规则中的一条新条款，认为它可能正是上述限制的来源。该条款写道：“可以构建原创游戏、某一类型下的游戏，以及基于用户自身设计与素材的游戏。不要构建对某一特定现有游戏的复刻，即使它被改名或被称为原创。”这一新规的本意或许是防止侵犯版权、规避 Anthropic 可能面临的法律风险，但实际效果却是 Claude 的 GitHub 页面上涌现出大量新问题。有报告称，Claude 甚至拒绝复刻开发者本人在项目早期完成的成果，仅仅因为后续开发需要用到相似的机制。

在 Reddit 等平台上，也有用户报告称，这一问题的影响范围已超出游戏领域。有报告提到，Claude 拒绝调用广受欢迎的“Reverse Engineer Anything”（逆向工程一切）能力，而这一能力此前被用于多种用途：从破解智能电视的厂商锁定，到为汽车信息娱乐系统增添功能，甚至包括将电子游戏重新编译到其他平台运行。
