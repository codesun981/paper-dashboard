Anthropic 刚递交招股书一周，自家最赚钱的产品，产品负责人已经坐到了对面。

今早，前 Claude Code 产品负责人 Cat Wu 在 X 上宣布加入 OpenAI，出任核心产品组的产品负责人。一天前，她刚告别了 Anthropic ，堪称“无缝衔接”。OpenAI 总裁 Greg Brockman 立刻转帖欢迎。

这已经是十天内，Claude Code团队离开的第三位核心成员。前段时间，离开的分别是Claude Code的桌面版之父Anthony Morris 和 Agent 核心工程师 Thariq Shihipar。而这个时间点，Anthropic 正好站在了上市的紧要关口。

Cat Wu 的离职之所以震动硅谷，不只是因为她换了阵营，更因为她带走了这条最赚钱产品线的完整方法论

Cat Wu，真名是Catherine Wu，她是硅谷 AI 圈炙手可热的华裔明星产品经理。

作为 Anthropic 旗下王牌 AI 编程工具 Claude Code 和办公智能体 Cowork 的产品总负责人，她与“Claude Code 之父” Boris Cherny 并称为 Anthropic 团队的“蝙蝠侠与罗宾”，是亲手将 Claude Code 从一个内部小工具打造成全球爆款的灵魂人物之一。

她还曾是普林斯顿女学霸，大四就在校内孵化器合伙开发了协作白板软件Scratchwork；在大厂与独角兽历练过，写过代码，研究过数据；还当过三年风险投资人，专注开发者工具和AI基础设施。丰富的跨界经历，让她成了那种少见的既看得懂代码，也算得清商业账，还摸得准开发者想要什么的人。

2024年8月，她加入Anthropic，一开始是研究方向的产品经理。

那时，Claude Code 还只是 Anthropic 内部一个不起眼的实验性项目。Cat Wu 想试试这东西到底能做什么，就让它帮自己从零搭建一个强化学习环境。她花了几十个小时，反复描述需求、调整方向，从头到尾没有写一行代码。当环境最后真的跑通了，她被这次体验震住，转头申请转进了这个刚起步的小团队。

在那个团队里，她和技术负责人 Boris Cherny 组成了黄金搭档。Boris 负责写下最初的原型代码，盯下一步能做到什么；而 Cat Wu 负责把想法变成产品，并调动各方资源推向市场。她执行力极强，开创了极快的产品迭代模式，直接把研发周期从数月压缩到了几周、甚至按天来计算。

后来，她的职责进一步延伸到了 Claude Cowork，探索 AI 在团队的工作场景。

如今，Claude Code 是全球最火的 AI 编程 Agent 之一，大量开发者使用。2026 年 2 月，Anthropic 在 Series G 融资公告里披露，Claude Code 的年化收入运行率（ARR）已经超过 25 亿美元，较年初直接翻倍。

放眼整个科技发展史，这都是增长最快的企业级软件（SaaS）产品之一，而它在 2025 年 5 月才刚刚向公众开放。 Cat Wu 执掌的产品线，就是这条收入曲线最核心的增长驱动力。

Cat Wu 是个反传统的人，在 Anthropic，她重新定义了"AI时代产品经理该怎么干活"。她在播客里公开讲过几条方法论，至今被同行奉为圭臬：

比如，长 PRD 已死，在模型能力几个月一变的今天，PM有想法就自己或者让AI快速搓一个能跑的原型，直接在运行和评测中迭代产品；还有“三个月报废原则”，任何半年以上的产品规划都会失效，只要今天能改善体验就立刻上线。她甚至在升级新模型时，干脆利落地砍掉了团队辛辛苦苦攒下的 20% 旧提示词补丁；她鼓励工程师做主线之外的“支线任务”。在这种鼓励自由探索的氛围里，工程师们在日常闲聊、下午茶交流里自发撞出了很多经典功能：现在风靡全球的 Claude Code 桌面端、极具灵性的“反问用户（AskUserQuestion）”功能，都是这么来的。

在离职贴中，Cat Wu表达了对 Claude Code 的自豪，这个产品从早期需要用户逐条手动审批权限，到如今可以信任模型自身判断，自动完成权限审批，已经完成了关键的跨越。而她在这一旅程中收获的感悟，正如她此前在播客分享的，打造 AI 原生产品最重要的一件事，就是学会放手。

或许会有人问，她在 Anthropic IPO 前夕离开，岂不是会损失一大笔钱？其实不然。

有网友指出，她在 Anthropic 待了大约 26 个月。按硅谷常见的四年期权规则，她已经拿到了大约一半的股份。尽管在公司上市前，这些期权只是“纸面财富”，但只要公司完成敲钟，她手里已经兑现的那部分依然可以套现。

也就是说，她已经拿到了财富自由的门票，无需继续被“绑定”在公司。

事实上，选择在此时退场的并非只有她。就在 10 月 24 日，团队另外两位核心骨干 Thariq 和 Anthony 也抢先一步宣布离职。紧接着的两天后，Anthropic 正式向 SEC 递交了 S-1 招股书，计划 11 月 9 日启动路演。招股书上的数据极其亮眼：2026 年上半年营收超 162 亿美元，估值直指万亿美元量级。

Cat Wu 离开的时机，正值这家公司从“创业神话”蜕变为“上市公司”的前夜。对于留下来的员工，上市意味着财富狂欢；但对于 Cat Wu 这个刚把产品从零带到 25 亿美元 ARR（年度经常性收入）的“一号位”来说，此时正是她职业声望的最高点。带着这份耀眼的战绩，她刚好顺理成章地开启下一段冒险。

资本市场并不关心她个人少拿了多少钱，投资者更在意这种“集体离职”传递出的危险信号：

Claude Code是Anthropic商业化的主引擎，是这家公司对抗OpenAI代码产品最重要的一张牌。在短短十天内，这条核心业务线的产品一把手、桌面版负责人、Agent 核心工程师接连出走，一号位甚至直接跳槽到了最大的竞争对手那里。这在任何一家冲刺IPO的公司身上，都是投资者会反复掂量的治理问题。

Cat Wu 去 OpenAI 后，直接向 OpenAI “重置大神” Tibo 汇报。

Tibo 可不是一般人，他之前在 Google DeepMind，进入 OpenAI 后，一路主导了早期大语言模型、ChatGPT 到 Codex 这条核心产品线。把Claude Code 的产品一号位放到他手下，说明 Cat Wu 接手的不是什么边缘项目，而是OpenAI整个智能体产品线的产品中枢。

她曾在 Anthropic 跑完了完整闭环，懂得如何把实验室里的模型能力，打磨成开发者离不开的产品。而这，恰恰是 OpenAI 当下最缺的。

接下来，她会和负责企业产品的Nick Turley、负责消费级产品的Ashley Alexander协作，专门打造团队级的 AI 助理。

另一件值得注意的事，就在 Cat Wu 入职前一天，OpenAI 宣布收购 Pierre Computer。很多人第一反应是 OpenAI 又在做个竞品打 GitHub，其实根本不是一回事。

传统 Git 架构从设计之初就是给人写代码的，一个开发者一天提交十几次代码，版本管理、权限划分怎么都够用。但如果一个团队里同时有前端、后端、测试五六个 Agent 不停往仓库里写代码，老的 Git 架构很快就会在反复的版本冲突、权限越界里投降。

Pierre 解决的就是这个问题，它主打面向 AI 智能体的原生代码存储，专门处理海量 Agent 高速并发写代码时的版本管理、并发读写难题，旗下那两个开源代码库 Trees 和 Diffs，早早就集成进 Codex 了。再加上 OpenAI 内部自研的 Git 系统 Pando，把代码推送的延迟压到了实时协作能用的水平。

把这些动作串起来看，OpenAI 的意图已经藏不住了。它不想只当一个"帮你写代码的AI"，而是要打通从想法、写代码、存代码、管版本到发布的整条链路，把 Codex 做成人和 AI 协同开发软件的主平台，正面挑战微软手里的 GitHub。

现在行业都在说 “团队 Agent 是下一个战场”，但为什么 Agent 现在始终迈不进企业生产环境？

根本不是写代码的准确率不够，是团队场景里没人敢真用，你敢让 Agent 直接碰生产目录吗？它不小心改了同事写的核心模块，没跑测试就提交了，出了线上事故谁负责？

什么场景下 Agent 可以直接改文件、什么操作必须停下来拉人审批、好几个 Agent 同时干活的时候怎么拆任务才不会互相打架，这些细碎的判断，全是摸出来的产品手感，而这恰好就是 Cat 在 Claude Code 从 0 磨了两年的经验。

当未来 Agent 写完代码，另一个负责测试的 Agent 自动跑检查、预检，人只需要在关键节点拍板就行，OpenAI 内部把这种原生为 Agent 设计的新工作流叫 “Reset”，目前，它有 10 亿用户，做团队级 Agent 是顺势而为。

相较而言，Anthropic 有最好的代码模型，但只有几十万开发者用户的盘子；Cursor 靠开发者口碑起来，但缺底层模型能力和基建。

到这一步，人、技术、基建三块拼图落位，OpenAI 才真正拿到了团队 Agent 赛道的入场券。
