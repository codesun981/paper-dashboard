Kimi Hosted Agents（托管智能体） 将支撑 Agent 运行的 Harness 作为云端服务提供（Harness as a Service）。企业和开发者无需自行搭建和维护运行框架，即可获得 7×24 小时的托管环境，支持长程任务执行与多智能体高效协作。 企业可以按业务需求配置 Agent，快速构建两类业务应用：

  1. 面向内部业务：集成到企业内部系统，提供业务监控、研究分析、运维响应等任务。
  2. 面向产品用户：嵌入企业对外提供的产品，提供 App 内的投研助手、游戏内的策略顾问等 Agent 服务。

为保障 Agent 安全可控地运行，Kimi Hosted Agents 提供独立沙箱、网络访问权限控制，企业可设定操作边界，并在必要时随时中止会话；执行过程留痕可查，支持审计导出；清晰的计费规则与用量报表，也让企业能够掌握各个 Agent 项目的资源消耗与费用。 产品定价：托管智能体采用「按量计费」模式，费用三部分构成：模型推理 tokens、沙箱运行时长、插件调用次数构成，详见 托管智能体定价。

何时使用 Kimi 托管智能体

Kimi 开放平台目前提供以下两种产品：

快速开始

告别自建 Harness，专注业务应用开发

让 Agent 投入生产，企业通常需要投入几个月构建一套可靠的 Harness 底座：搭建代码执行环境，实现上下文与会话管理、工具调用、权限控制、任务中断恢复等能力。在 Agent 上线后，企业仍需花费大量时间和成本持续维护这套 Harness 系统。 现在，依托 Kimi Hosted Agents 提供的 Harness 框架与托管环境，企业可以快速定义任务、接入工具，缩短从原型验证到应用上线的开发周期。底层运行环境的维护与升级由 Kimi 负责，团队无需反复投入基础设施适配与运维，可以更快响应业务需求、迭代应用功能。

调用官方技能与插件，加速业务功能开发

Kimi Hosted Agents 提供 140+ 个技能（Skill）与 30+ 个插件，覆盖联网检索、专业数据查询、办公文档处理和内容生成等任务，开发者可按需调用，减少逐项接入工具的开发工作。除官方技能与插件外，也支持自定义技能、插件、MCP 服务与自定义工具，便于接入自有工具和数据源，让智能体适配具体业务流程。

数据源与插件仍在持续拓展中

接入 Kimi Inference Hook，让 Agent 在企业安全规则下运行

Kimi Hosted Agents 可结合开放平台的独立安全组件 Kimi Inference Hook，对接企业自建或采购的安全服务，在每次模型推理前检查任务输入与工具返回内容。 安全检查规则由企业定义，放行或拒绝由 Kimi Inference Hook 执行：只有通过企业安全检查的内容才会进入模型推理，未获准的隐私与敏感数据将被拦截在推理之前。

Kimi Inference Hook 目前仅针对企业认证用户定向开放，如有业务需求，请联系 Kimi 官方销售。

在自有主机上执行沙箱工具

自托管环境 把沙箱工具放到你管理的主机上运行，模型调用、智能体编排和会话管理仍由平台负责。需要访问内网服务，或在自己的执行环境中处理代码、文件和网络时，可以为会话绑定自托管环境。

自托管环境仅向企业认证用户开放，完成企业认证后即可使用。

官方 Agent 模板与最佳实践

首批提供 12 个官方 Agent 模板，覆盖金融研究、游戏开发、运维响应和出海社群运营等场景。企业可将模板复制到自己的项目空间，接入内部业务系统和私有数据库，按需调整任务流程。官方模板与自建案例页面介绍 Agent 架构、核心设计和配置方式，并说明如何从最小可用版本开始搭建。
