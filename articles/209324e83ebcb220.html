手里几台 VPS ，每次续费前、换 IP 后都要查一遍：IP 干净吗、原生吗、DNS 漏吗、流媒体解锁吗、延迟测速怎么样。脚本找了一堆，输出还得自己一行行看。

我就写了个单文件 Python 工具，开源 MIT ，叫 NetPulse 。用法是本地一条命令：

```
python3 netpulse.py --host root@vps-a --host root@vps-b --json
```

经 SSH 在远端执行，结果拿回本地，多机自动出对比表。`--json` 输出结构化结果，丢给 Claude / Codex 直接出中文总结。官网首页放了一句 prompt ，复制粘贴就能用。

检测项：IP 纯净度（机房 / 代理标记）、原生 IP （ Team Cymru ASN 注册地 vs IP 属地）、DNS 泄露、11 项流媒体解锁、ChatGPT / Claude / Gemini API 可达。AI 可达走 API 端点探针，401 （无 key 但请求到网关了）算可达；首页 403 很多时候只是反爬，我不拿它当证据。

延迟是三次采样取中位数；测速响应不足 1MB 直接判 error ，不把错误页算成速率。查不到的就标 unknown ，我不编"风控分"这种自创指标。

所有检测都在你本机 / 你的 VPS 上跑，IP 数据不经过第三方网页服务。

GitHub： https://github.com/Genuifx/NetPulse
官网： https://genuifx.github.io/NetPulse/
