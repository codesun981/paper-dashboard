Chrome 157 修复了 213 个漏洞，远高于平均水平

RC-pulish • 2026-11-05 10:41 • 业界 • 阅读 1

谷歌再次修复了 Chrome 中的大量漏洞。在 Chrome 157 中，该公司修复了 213 个漏洞，其中七个被归类为 “严重” 。据目前所知，没有漏洞正在被积极利用。谷歌写道，这些漏洞修复包含在 Windows 和 macOS 的 Chrome 157.0.8103.38/.39 以及 Linux 的 157.0.8103.38 中。该公司已在线发布一份包含所有漏洞修复的列表。谷歌总共修复了 213 个漏洞。这相比仅仅几周前有所下降。今年 7 月，谷歌在两个 Chrome 版本中突然修复了数百个漏洞。

七个漏洞具有严重的 CVSS 评分。其中包括 WebGPU 实现 Dawn 中的两个缓冲区溢出以及多个释放后使用漏洞。大多数严重漏洞由外部研究人员发现。仅有一个漏洞标注为 “在 Claude 的帮助下” 发现，但那是 Anthropic 的一名研究人员发现的漏洞。实际上，部分借助 AI 发现的漏洞数量可能要高得多。安全研究人员正更快、更高效地利用它来发现漏洞。谷歌自身也利用 AI 进行漏洞修复。
