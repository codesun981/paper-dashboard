FindMyWeb

A project which allows you to build trackers which you actually own. The idea is to create a way for you to build your own trackers using the already existing networks without requiring you to own any vendor specific devices.

Supported networks

Why

Currently there are a lot of different networks for location trackers from a plethora of different vendors. This causes a lot of fragmantation and everyone requires you to own a device where their closed-source software runs without you knowing what actually happens with your location. The idea is to create a web interface for all of them and allow you to build your own open-source trackers.

How

The backend currently uses malmeloo's FindMy.py library to interact with Apple's network while the trackers run a custom Zephyr based firmware. You can find out more info in the setup instructions.
