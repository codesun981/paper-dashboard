Grok 也将为文本添加水印

RC-pulish • 2026-11-02 20:42 • 业界 • 阅读 4

AI 模型 Grok 将为文本输出添加不可见水印。 Grok 所属的 SpaceXSI 发给用户的电子邮件和其支持页面显示，水印将从 2026 年 11 月 7 日起生效，且仅适用于文本输出，不适用于图像。 SpaceXSI 将 “欧洲人工智能法案” 列为添加水印的原因。该法规将从那时起开始执行。人工智能法规中的一项义务是，AI 模型必须带有水印，以便能够识别 AI 生成的文本。 SpaceXSI 几乎没有提供关于 Grok 中水印具体如何运作的信息。推测其方式与 ChatGPT 和 Claude 等大语言模型添加水印的方式类似。简而言之，语言模型在选择同义词时会给某些生成的词更高的优先级。当文本中包含足够多这样的优先级标记时，就可以识别出该文本是生成的。水印将存在于所有 Grok 模型中，涉及 grok-4.7 、 grok-4.6 、 grok-4.5 、 grok-4.3 、 grok-4.20-reasoning 、 grok-4.20-non-reasoning 和 grok-4.20-multi-agent 。 SpaceXSI 表示，团队管理员可以通过其控制台关闭水印，但个人用户似乎无法这样做。水印也可通过 API 识别。 Responses API 和 Chat Completions API 将获得一个名为 x-watermark 的新端点，当文本包含水印时，该端点可以返回 true 。
