英伟达限制了什么？

受影响的主要是采用 Ampere 架构、GA102 和 GA104 核心的显卡，包括 RTX 3090、3080、3070 等。

这些显卡本身具备相应的计算能力，但部分 Tensor Core 运算路径受到硬件配置限制。开发者找到了修改相关配置的方法，让显卡释放出原本未能充分发挥的计算吞吐率。

这不是超频，也不是凭空增加计算单元，而是解除部分计算路径的吞吐限制。

英伟达限制的并不是显卡本身的计算能力，而是某种计算方式的运行速度。

简单来说，显卡明明有能力算得更快，但在执行某些 AI 矩阵计算时，却被限制了速度。

这次解锁就是绕过了这道限制，这不是超频，不会提升游戏帧率，但如果模型和推理引擎使用了这种计算方式，则可以提升性能。

KBlueleaf 认为，由于显卡原本就能通过其他计算方式达到类似的速度，解锁造成硬件损坏的风险应该很低。

Windows 也能解锁了吗？

可以，但目前还比较麻烦。

Linux 版本已经有多款显卡、不同主板甚至 Proxmox 虚拟机的成功案例。

Windows 版本则通过 UEFI 启动程序，在 NVIDIA 驱动加载之前完成解锁。目前只在有限的硬件配置上得到验证，并不是下载后双击就能使用。

两个项目都很新，涉及显卡底层操作，存在兼容性和稳定性风险，暂时不建议在主力电脑上直接尝试。

至于英伟达为什么设置这些限制，目前还没有官方解释。
