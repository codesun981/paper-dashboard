IT之家 11 月 19 日消息，微软与英特尔于当地时间 11 月 18 日宣布，双方将根据一项长期协议深化合作，共同推进微软 Azure 云基础设施建设，以满足不断增长的云计算和 AI 算力需求。

根据英特尔官方公告，双方将围绕先进封装、服务器处理器、内存技术及安全计算等领域展开合作。

此次合作的一项重点是英特尔代工服务（Intel Foundry）的 EMIB（嵌入式多芯片互连桥）先进封装技术。微软将成为首家宣布在 Azure 第一方自研芯片中采用英特尔 EMIB 技术的企业。

双方还确认了未来数年的英特尔 Xeon 服务器处理器供应能力，其中包括代号为 Diamond Rapids 的下一代服务器 CPU。与此同时，微软与英特尔将继续推进 Azure 硬件系统及云基础设施路线图的合作。

在内存技术方面，双方将合作推进支持 Compute Express Link（CXL）的英特尔 Xeon 处理器，以提升 Azure 数据中心的内存利用效率和系统性能。IT之家注意到，其合作还涉及英特尔 QuickAssist Technology（QAT）加速技术以及机密计算。

英特尔公布的测试数据显示，搭载 CXL 内存和 Xeon 6 处理器 Intel Flat Memory Mode 技术的 Azure M 系列 v4 虚拟机，在特定工作负载下性能最高可提升 2.3 倍，内存配置灵活性也得到提升。

在数据库性能方面，采用英特尔 QAT 技术的 Azure 虚拟机可将 SQL 数据库备份速度提升至原来的 2.5 倍。

此外，双方还将通过英特尔 Trust Domain Extensions（TDX）技术，为机密虚拟机在不同物理主机之间迁移时的虚拟机内存及 CPU 寄存器状态提供加密保护。

微软 Azure 系统与架构部门企业副总裁 Saurabh Dighe 表示，双方将结合先进封装、定制计算、内存和安全技术，为 Azure 提供更适合云计算及 AI 工作负载的基础设施。

英特尔代工服务执行副总裁、首席技术与运营官 Naga Chandrasekaran 表示，AI 基础设施正变得更加复杂，需要对芯片、封装、计算、内存和软件进行协同优化。通过在未来 Azure 基础设施中采用 EMIB 技术，双方希望结合异构集成的灵活性与规模化制造能力。
