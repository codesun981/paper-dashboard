01 Vibe-Trading 是什么

可以把 Vibe-Trading 看作一个面向金融研究的。你用自然语言提出问题，它可以调用行情和基本面数据、分析工具、策略与回测流程，并把结果整理成报告或运行记录。开源工作台

它覆盖 等多个市场。不同市场会使用不同的数据源和回退策略，具体能取到什么数据，取决于当前版本、所选数据源、网络环境，以及是否配置了相应的 API 凭证。A 股、港股、美股

项目也提供券商相关功能，但要区分和：行情查询、策略研究与历史回测，不等于实盘交易能力。券商接入还取决于连接器支持范围、账户授权和具体配置。“研究分析”“交易执行”

02 它的工作流程

  1. 判断需要哪些金融技能、工具、数据源，必要时安排多智能体协作。规划。
  2. 加载市场行情、基本面、文件或网页上下文。取证与取数。
  3. 生成策略草稿，并调用相应分析或回测工具进行评估。执行分析。
  4. 根据任务加入基准比较、风险指标、Monte Carlo、Bootstrap、Walk-Forward 等检验，并记录警告。验证。
  5. 生成报告、运行记录和可导出的代码或文件，供后续检查或复用。交付。

关键点是它试图让研究过程，而不是只给一个看起来确定的答案。对于失败或缺少有效观察的运行，项目也描述了停止并请求恢复信息的机制。可追溯、可检查

04 部署

Python 环境下有两条安装路径，选一条即可。

方式一 用 pip 安装

pip install vibe-trading-ai

方式二 用 uv 安装

uv tool install vibe-trading-ai

STEP 1 运行初始化命令

vibe-trading init

按提示选择模型提供商，并配置你需要使用的凭证。

最后问你要不要接入 这家 A 股数据服务商，可以按需填写；不使用时可跳过。Tushare

这里解释一下这个东西是什么：Tushare 是国内老牌的金融数据接口平台（tushare.pro），Vibe-Trading 拉取 A 股行情、财务数据时可以走它。token 就是你注册后在它网站个人主页拿到的一串凭证，相当于。“通行证”

需要的话，可以去 tushare.pro 注册一个，在“个人主页 → 账号与 TOKEN”复制过来粘贴。目前注册只有 100 积分了。

回车后，就完成部署了。这里多说一句，，这是常见的安全输入方式，不是卡住了。输入密钥时终端不会显示字符

05 其它功能

Vibe-Trading 支持模拟交易，也为部分券商提供真实下单能力，但不同券商的支持范围不一样。模拟下单可通过券商沙盒或本地模拟进行；真实下单则只适用于满足项目条件的连接器，需要用户配置券商账户，并经过授权与风控控制，例如交易额度限制、审计记录和停止开关。部分连接器只支持只读或模拟交易，并不支持实盘下单。

需要特别说明：Vibe-Trading 的 MCP 接口。把它接入 Agent，主要是调用行情、研究和分析能力。不提供下单工具

关于模拟和真实交易类这里就不多介绍了，感兴趣的朋友可以参考项目文档，或借助你的 Agent 去深入研究。

06 它适合谁

如果你愿意检查数据、理解基本回测假设，也想把行情研究、策略草拟和复盘流程整理得更顺手，Vibe-Trading 值得体验。它能帮助你把研究任务流程化，让结果和过程更容易留档。

如果期待输入一句话就得到可靠买卖信号，或者认为一段漂亮的回测就能证明策略有效，那就容易。把它当研究助手，保留判断和核验，才是更稳妥的用法。误用这类工具

最后再次提醒，不论是 Vibe-Trading 还是别的工具，只建议做为你的辅助，。不应该代替你的思考

写在最后

Vibe-Trading 这类工具真正的价值，不在于替你拍板，而在于把这条链路变得可复现。工具负责跑得快、记得全，判断仍然在你手上。取数、分析、验证、留档

把它当研究助手，而不是替你做决定的东西
