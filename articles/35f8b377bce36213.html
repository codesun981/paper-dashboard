Physical Intelligence 推出 Pi API beta，开始把「机器人大脑」按 API 卖。具身智能不缺融资和 demo，难的是私有化部署、数据合规与验收责任，这三关决定谁能把它卖成生意。

具身智能行业最近被一个老问题重新击中，机器人“大脑”，到底该怎么卖？

过去两年，具身大脑公司普遍不缺融资、不缺论文、不缺demo，真正难的是商业化。模型能力看起来都很强，但落到实际操作上，往往还要面对私有化部署、项目制交付、数据合规和验收责任。也正因如此，10月13日当Physical Intelligence（PI）宣布推出Pi API beta版时，迅速引起了行业的讨论。

这家被视为“机器人领域AI大脑独角兽”的公司，其π系列模型长期处在第一梯队：π0、π0.5常被公开论文和仿真基准用作强基线。今年4月发布的π0.7，在多项任务上追平了PI此前的专用模型，还能在没专门训练过的任务上，保持不错表现。

如今，它把“上传机器人数据—托管微调—云端推理、策略生成—评测回流”做成一条服务链，尝试把具身大脑按API卖出去。

它不是第一个开放机器人模型能力的公司，但它把这件事做得更像一个产品。就在其官宣后，一家位于旧金山、其核心成员多来自英伟达的机器人团队Dream-1，也正式发布其创业后的首个模型，并提供API服务。当“大脑”开始可以被调用，大脑公司、本体公司和整个具身智能行业，会被带向哪里？

01.PI把具身大脑做成了API

PI不是突然决定做API的。具身算法研究员硅基漫步对PI的举动并不意外，“PI一直专注于大脑，其联创在社交媒体上也一直发布大脑在更新和部署相关的思考。”

这家公司从成立起，就很明确自己要做什么，不做本体，专做通用具身智能模型，也就是机器人世界的“大脑供应商”。

2024年成立时，PI的创始阵容几乎囊括了机器人学习领域最顶尖的一群人。CEO Karol Hausman曾任Google DeepMind资深研究科学家；首席科学家Sergey Levine是UC Berkeley教授，联合创始人Chelsea Finn来自Stanford；工程侧有SayCan等语言模型接机器人的核心作者Brian Ichter、主攻跨本体学习与机器人规划控制的Quan Vuong，以及曾在Tesla和Anduril做硬件产品化的Adnan Esmail，商业化一侧有前Stripe高管Lachy Groom。投资方里，则出现了OpenAI、红杉、Thrive、Lux、CapitalG，以及亚马逊创始人贝索斯等名字。

资本愿意押注PI，不只是因为“人很强”，更因为这批人对机器人的判断一致：机器人现阶段缺的不是手、不是腿，甚至不是更贵的硬件，而是智能。

Karol Hausman在红杉的播客节目里提到，硬件这些年在进步，比如更灵巧的手、更好的人形本体，但这并没有解决根本问题，仍然没有足够的智能去操作这些机器人。他的判断是，哪怕用简单夹爪，机器人早该能切菜、做饭。真正卡住行业的，是机器人还不够聪明。

这也是PI和很多机器人公司最大的不同。它不是先造一个机器人，再给它配模型，PI想做的是“物理世界的通用AI大脑”，让同一套模型跨机器、跨环境、跨任务工作，而不是被某一个场景绑死。

PI对路线的选择也很坚定。它不太相信传统机器人那种“感知、规划、控制”分模块堆系统的方式，而是押注端到端模型。它也不太满足于仿真环境里的漂亮曲线，更强调真实世界强化学习和部署后的数据回流。简单说，就是先把模型放到真实场景里干活，让失败、纠正、再部署形成闭环，靠真实数据把能力磨出来。

这也解释了PI为什么要做API。API本质上是把它最相信的东西产品化，把在真实任务里迭代模型的整套方法交到客户手里。

在PI之前，行业并不缺“开放”。

但之前开放的更多是模型权重、SDK、工具链、研究模型和平台插件。开发者可以下载模型，可以调接口，可以基于开源项目做二次开发，大多数情况下，拿到的仍然是一个“能力毛坯”。用户要自己准备数据，自己训练或微调，自己部署，自己评估，自己承担上线后的效果。

PI这次的不同在于，它把第三方数据、托管微调、云端推理、评测回流打包成了一条链。

客户上传自己的机器人数据，在PI管理的算力上完成微调，再通过云端网关调用模型，随后客户在真机上测试，根据失败情况决定下一轮补采哪些数据。对很多没有模型团队，或者不想重投入训练模型的公司来说，这条路显然比从零自研更快。

当然，这不意味着卖API没有门槛。

机器人方向研究生、前方舟无限创始团队成员陈翔宇表示，具身大模型API在工程上并不神秘。网关、鉴权、微调、日志、评测、计费，这些和LLM API很像。真正难的是，模型能力要可以被复用：第三方数据上传微调后，还能保持泛化；换一个本体、换一个场景、换一批客户，模型还能工作。

成本则是另一个需要考虑的因素。新加坡具身产品应用方向创业者家斌表示，PI目前没有公布定价，beta版采用申请制，开发者需要先说明自己想做什么。PI展示的大部分案例跑的都是云端托管推理，部分早期部署已经暴露出网络连接问题。对客户来说，这意味着除了调用费用，还要为网络稳定性买单。

02.PI之后，同行慌了吗？

在具身大脑这条赛道上，PI是很多同行默认的参照系，它把具身大脑做成API后，同行会慌吗？

多位受访的具身智能从业者、研究者和创业者都承认，PI这一步会实实在在地影响行业，但还不至于立刻改写格局，也不会马上带走客户。具体的影响，因企业所处位置而异。本体公司是PI的潜在买家，只做大脑的公司是它的直接对手，全栈公司则要重新评估自己的护城河能撑多久。

没有自研“大脑”的本体公司，已经表现出了尝试的意向。先看买家。

硅基漫步告诉「AIX财经」，很多硬件和应用公司并不想自己训练VLA、WAM、世界模型。与其重投入建模型团队，不如先接PI的API，验证自家本体在更强大脑驱动下的能力上限，尤其希望借海外头部模型拉高自家硬件上限。如果PI的模型能让本体完成更多任务、适配更多场景，本体厂当然愿意试。

但他们纠结的点也在这里，测试会付费，长期部署未必。

家斌解释，本体公司测试会付费，但卖给应用公司进行部署时，持续的API费用企业会嫌贵。在国内，大量场景里人工成本仍然相对低，机器人替代人力的ROI本来就比较低。如果再加上一层持续API费用，很多项目的账就算不过来了。所以，更现实的做法是用PI的模型摸清自家本体的能力上限，找到值得投入的场景，再决定后续路径。

再看对手。只做大脑的公司，感受最为微妙。

真正做模型的人，对PI做API并不意外，这是很多大脑公司都想过的一条路。硅基漫步观察到，具身模型行业在通过waitlist、beta API等方式做外部测试，大家都在思考可行的落地方向。

但在他看来，国内很多具身模型团队还没有证明自己到了“可以被第三方反复复用”的程度，因此他更想做的是，拿相同数据测一测，PI训出来的模型和自己的模型差距到底有多大。

这恰恰是PI给同行带来的真实压力。过去各家模型都在自己的demo里展示，很难横向对照。API一开放，任何一家本体公司都可以拿同一批数据、同一台机器，去对比PI和国内模型的效果。

最后是全栈公司。

短期看，这类公司既有模型也有本体，最不容易慌。具身行业资深工程师Gashero对PI卖API不看好，“但这意味着，客户要上传自己的训练数据。”对机器人公司来说，真机数据、失败样本、场景SOP往往就是核心资产。他还表示，此举还可能会面临数据泄露风险，“一旦自身数据被PI拿去训练，等于用自己的护城河，免费滋养一个同时服务所有同行的通用大脑。这也是为什么，越强、越有场景的公司，越不会轻易把核心数据交出去。”它提供的服务更接近AI Infra类，托管微调、云端推理、评估闭环。

但长期看，全栈公司面对的压力反而更复杂。

家斌告诉「AIX财经」，时间越长这类公司面临的威胁越多。他举例说，像“类手构型”的三指、七自由度灵巧手，目前全球就只有几家在做，但明年可能就是十几家了。“就像PC时代零部件专业化之后，整机厂价值越来越像拼装。”，“现在全栈公司的优势，很大程度来自于第三方的关键部件和模型能力供给不足。”如果大脑模型、灵巧手、执行器、传感器都逐渐供给充足，全栈公司的价值会被重新定价，

PI带来的第一波反应，三类公司的反应各不相同，但多位受访者都提到一个共同判断，具身行业不需要每家公司都重复造一套底层模型，能力有机会向少数基础模型集中。言下之意，现在的大脑公司太多，泡沫很大。陈翔宇认为，PI做API对同行带来的直接冲击是，国内声称做大脑、也融到资，但技术能力不行的团队，会迎来真正出清。

03.国内会不会跟着做API？

国内是否会跟进，不止一位从业者表示，大概率会，但不会照抄PI。

家斌判断，PI最先可能激发阿里云这类通用大模型平台型公司去做机器人API付费模式，“训模型、托管模型、开放API、计费结算、服务开发者，这套模式本来就是这类公司的强项。”国内接下来更可能先长出“平台型具身模型服务”，而不是立刻长出很多个“中国版PI”。

这也意味着国内和PI是两条路，PI是把自己的核心模型做成服务，赌的是模型能力本身能成为基础设施；云厂商做具身模型服务，更像在原有算力和模型平台上长出一个新品类。前者是“大脑公司服务化”，后者是“平台公司具身化”。

至于国内具身大脑公司是否会跟进，目前各家并没有明确表明态度。

在和多位从业者交流时，我们发现头部模型公司不是不想跟进，而是要先算清一笔账。开放API虽然可能带来新收入，但也会带来风险，例如，模型能力被放到同一套接口下直接比较，真机数据托管涉及合规和商业机密，客户还可能借此压价。

因此，他们更想先观望PI的API成交效果，重点关注三个维度。

首先，这个API到底能干多完整的活。如果只是“传一点数据，换回一个更聪明一点的模型”，那还不是完整的具身大脑服务。行业更期待的是，能接上客户的机器人数据，并帮客户微调出真正能部署到自己机器上的模型。

其次，这个服务能不能装进客户自己的环境里。

只支持公有云API还远远不够，对于很多工业、政企、门店客户来说，支持私有化部署、专有云、边缘部署很关键，他们的数据不能随便出域。

最后，出了问题谁负责。机器人任务失败后，平台如果只提供日志和评估，不参与验收、回滚和赔付，责任就写不进合同，而客户更愿意为明确的结果付费。

这是具身API在全球都要过的三关。只是在国内，客户更习惯项目制和验收制，数据更强调不出域，纯API的ROI更难算。

因此，国内短期很难一步跨到纯API收费，但PI提前走了“大脑能力服务化”的路，哪些关卡必须过，行业看得更清楚了。陈翔宇甚至把PI类比成Momenta，看中的是商业模式。Momenta不造车，它把智能驾驶方案卖给多家车企，PI想在机器人行业做的也是这件事。不过，Pi API仍处于beta阶段，定价和成交都未公开，这个商业闭环能否跑通，现在下结论还早。

变量也不只来自PI。GPT-6这类通用大模型的压力正在袭来，“如果它们未来也能把VLA做得很好，说明技术路线正在接近收敛，具身智能会更像智能驾驶一样走向规模落地。到那时，竞争不只有模型，还有硬件、供应链、场景和本土交付。”陈翔宇表示。

对国内具身公司来说，接下来的压力来自两个问题：自家的模型凭什么被客户持续调用，以及当通用大模型也具备类似能力时，自己还有什么不可替代。
