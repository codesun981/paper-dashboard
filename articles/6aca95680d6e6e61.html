IT之家 10 月 23 日消息，科技媒体 Windows Latest 今天（10 月 23 日）发布博文，报道称微软正低调测试一款适用于 Windows 11 系统的 AI 应用，内部开发代号为 Project Pantheon，测试版本名称为 Context Vault，可视为“回顾”（Recall）功能的不录屏版本。

“回顾”功能在上线后因为会自动截取屏幕而引发巨大隐私争议，而这款 Context Vault 应用为了规避该隐私风险，只保存用户主动选择的内容，更接近一个可检索、可向 AI 提问的“第二大脑”。IT之家附上相关图片如下：

用户可将网页、文件、截图、复制文本、音频和视频保存为“记忆”，并按主题归入收藏集。应用内建的聊天功能可对这些资料提问，例如总结某个收藏集、梳理近期工作内容，或基于资料起草内容。

该项目还深度整合 Windows 系统入口：用户可从浏览器扩展、文件资源管理器、共享菜单、屏幕截图、Click to Do 和剪贴板保存内容。在文件资源管理器的共享菜单中，Context Vault 已与 WhatsApp、Outlook 等应用并列。

这款 Context Vault 应用还支持 Model Context Protocol 协议，让 Claude、Cursor 等第三方 AI 应用可调用用户保存的记忆。
