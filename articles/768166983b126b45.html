Cloudflare Tunnel 是 提供的内网穿透工具（带网络），它能将家里的 NAS、服务器或本地网站安全地发布到互联网上，无需公网 IP，也不需要在路由器上开放端口。Cloudflare

在 AI Agent 时代，以及 IPv4 紧缺的时代，非常方便，你可以在本地电脑中发布程序，直接通过 上线测试。Cloudflare Tunnel

而 是这个内网穿透工具的客户端，负责建立和维持与 Cloudflare 之间的加密连接。cloudflared

如何查看 cloudflared 版本？

青小蛙觉得，让你去一台一台查看很不现实，因为完全记不得哪些地方用了。所以，从 进入： 查看版本，是最方便的：Cloudflare 控制台联网 → Tunnels

需要升级的版本：

  • Linux、Windows、Docker：低于 2026.10.2
  • macOS（非 Homebrew 安装）：低于 2026.10.3

如何升级 cloudflared？

建议升级交给 AI Agent 来办，很方便：

帮我升级 cloudflared

就好了。

如果要手动升级，可以试试：

Linux：

sudo apt update
sudo apt install --only-upgrade cloudflared
sudo systemctl restart cloudflared

macOS：

通过 Homebrew 安装的用户：

brew update
brew upgrade cloudflared

Windows：

通过 WinGet 安装的用户：

winget upgrade --id Cloudflare.cloudflared

更新后重新启动 cloudflared 服务或进程。

Docker：

拉取新镜像：

docker pull cloudflare/cloudflared:2026.10.3

随后使用新镜像重新创建容器。如果使用 Docker Compose，执行：

docker compose up -d --force-recreate
