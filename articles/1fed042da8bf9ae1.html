Changelog

This page documents the changes in each Kimi Code Desktop release.

1.1.0 (2026-10-14)

Features

  • Linux version now available, with AppImage, deb, and RPM installers.
  • Remote Control: control the local Agent from another device via a link or QR code (enable in Settings).
  • New File Tree panel in the right sidebar to browse and preview workspace files.
  • Progress updates: see the Agent's real-time work progress in conversations (off by default; enable in Settings → Lab).
  • New kimi app command: run it in the terminal to open a new desktop chat in the current or given directory.

Polish

  • In-app browser improvements: download progress, Agent-handled popups, and pausable Agent control.
  • Messages queued or sent while the Agent waits on background tasks now arrive immediately.

Bug Fixes

  • Fixed a crash on some Macs when chat content contains emoji.
  • Fixed missing line-by-line diffs and stuttering diff computation for large files.
  • Fixed side chat snapping back to the bottom when scrolling up during streaming.
  • Fixed display issues: hidden session list on small screens, vertical @-menu filenames, and opaque frosted backgrounds.

1.0.4 (2026-09-24)

Polish

  • File watching is back on by default; outside edits to config or AGENTS.md apply automatically.

Bug Fixes

  • Fix repo-local Git config (such as hooks) not taking effect in trusted workspaces.

1.0.3 (2026-09-23)

Features

  • Clicking a local HTML file in the transcript opens it as a real web page in the built-in browser on the right, so you can verify the result directly.
  • Browser downloads now support pause, resume, cancel, and retry, with download speed and remaining time shown.
  • Valid line-leading / commands are highlighted in the composer, with a parameter hint when no argument is entered yet.
  • Right-clicking a file name in the transcript offers copying its path or revealing it in the folder.
  • New settings toggle for automatic session title generation; turn it off to stop AI naming for new sessions.
  • Free-plan accounts sending messages with subscription models are now prompted to upgrade.

Polish

  • Markdown tables in the transcript use rounded frames and can expand to the full transcript width.
  • Scheduled tasks show readable names, schedules, and details in the transcript.
  • Address bar suggestions support highlighting and deduplication, and distinguish between suggestion types.
  • Expanded tool panels show the full Bash command.

Bug Fixes

  • Fix a security vulnerability where malicious web pages could execute arbitrary commands through the local embedded server.
  • Fix long sessions freezing on open, dropped frames during streaming, and high memory usage on mobile.
  • Fix the confirmation dialog spinning forever after deleting a session.
  • Fix the subagent model setting showing as unconfigured in the UI and not taking effect after saving.
  • Fix a series of issues with Swarm tool cards and member status display.
  • Fix session titles being regenerated and overwritten after continuing a forked session.
  • Fix the built-in terminal: Cmd+K no longer pops up the search panel by mistake, and Ctrl+C fails to copy when text is selected.
  • Fix the sidebar and work panel overlapping and fighting each other when both are open.
  • Fix side chat not showing a failure card on request failure, and the side-chat entry staying clickable on the empty new-session page.
  • Fix task notification cards appearing out of order inside collapsed turns.
  • Fix unstable dragging of pinned screenshots on Windows.

1.0.2 (2026-09-19)

Features

  • Built-in browser overhaul: the transcript shows the Agent's live browsing activity, grouped into activity summaries with sources listed; the page glows while the Agent controls a tab; the Agent proactively shows pages you ask to see.
  • New "Open in default browser" button in the address bar; download history shows live progress and file actions.
  • The Agent can search with your configured search engine.
  • Redesigned providers settings page.
  • Quit confirmation is now an in-app dialog.
  • Hover to reveal subagent names.

Polish

  • Faster startup paint, lighter sidebar updates, and bounded session search.
  • The transcript no longer restyles when the composer wraps.
  • Screenshots are no longer re-decoded when exporting or copying.
  • The screenshot global hotkey is limited to stable builds.

Bug Fixes

  • Fix page capture failing when the window is hidden or minimized.
  • Restore ctrl+` as the bottom terminal toggle and drop the new-terminal-tab shortcut.
  • Keep the current view after login instead of jumping to the most recent session.
  • Fix address bar suggestions not updating in place while typing.
  • Fix cmd-clicked and middle-clicked links not opening in a new tab.
  • Fix the Agent's browser URLs being cut to a single character.
  • Fix the download save dialog not appearing on the app window.
  • Fix sub-agent approval and question requests not being surfaced.
  • Fix session restore flicker; turn file cards are limited to the latest 3 turns.
  • Fix the transcript jumping while resizing the window or toggling dock panels.
  • Windows: detect editors installed in custom directories, and preserve fullscreen window chrome and media controls.

1.0.1 (2026-09-17)

Features

  • New "Open file" button in the changes diff detail view.
  • Hovering a link in the transcript shows the full URL with open actions.
  • Browser tool calls are visualized in the transcript.
  • Image preview supports gallery navigation and a right-click menu.
  • The confirm dialog for removing a workspace now spells out what removal does.
  • Screenshot output actions are reordered to close, pin, save, copy.

Polish

  • Unify the styles of the providers, plugins, shortcuts, and browser tabs in settings.
  • Improve interface clarity on low-DPI displays.

Bug Fixes

  • Failed-turn cards now show the full provider error.
  • Edit and View menu role labels are localized.
  • Multiple built-in browser fixes: Agent clipboard and undo keys not working on macOS, pages going blank when a non-http link is blocked, and element refs and wait polling failing intermittently.
  • Fix toasts being hidden behind modal dialogs.
  • Fix the app root scrolling when the right panel opens.
  • Fix tool call rendering and chat interactions in side chat.

1.0.0 (2026-09-17)

Features

  • Kimi Code Desktop is officially available: it carries the Agent core of Kimi Code CLI into a graphical interface, where you open a project, talk to the Agent, and ship changes in one window. Available for macOS (Apple Silicon / Intel) and Windows.
  • Every step stays visible: tool calls, thinking, and the files changed in each turn are all presented in the interface; sensitive operations raise approval prompts, and three permission modes (Always Ask / Ask When Needed / Never Ask) keep you in control.
  • A complete workflow from conversation to delivery: goal mode keeps long-running objectives moving and can be paused, resumed, or cancelled; plan mode proposes an approach before touching files, and the plan can be reviewed and refined; long tasks can move to the background, where you can check progress at any time.
  • Built-in browser and visual annotation: the browser lives in the right panel, with tabs that stay with the session and page context shared with the Agent; screenshot annotation, text selection comments, @ file mentions, and element picking on web pages tell the Agent exactly what to change.
  • Sign in to use official Kimi models out of the box, or connect third-party model providers; sessions, projects, and background tasks are managed in one place, with plugins to extend capabilities.
