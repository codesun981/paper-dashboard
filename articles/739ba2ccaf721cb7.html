Usage notes

NoteOutput budget change (OpenAI Chat Completions): Starting with qwen4-max-preview, max_tokens is equivalent to max_completion_tokens. Both limit the combined tokens for thinking and the final answer. Thinking consumes part of the same budget, so a limit previously sized for the answer alone may truncate output. Allow room for both when choosing the limit. Existing Qwen models retain their previous behavior. See API compatibility upgrade notice.

  • Thinking: Enabled by default. Choose low, medium, or xhigh (default). Do not set reasoning_effort and thinking_budget together. See Thinking.
  • Multi-turn conversations: Chat Completions enables preserve_thinking by default. Return all historical thinking in the assistant messages' reasoning_content field; do not concatenate it into content.
  • Multimodal input and tool calling: See Image and video understanding for visual input, Function calling for tool definitions and workflows, and Structured outputs for output formats.
