  1. MiniMax H3 简介

MiniMax H3 是 MiniMax 推出的开放通用多模态视频模型，统一理解文本、图片、视频和音频输入，支持文生视频、图生视频、全能参考生成等任务。输出时长 4-15 秒，分辨率支持 768P/2K。

  1. WanGP 简介

WanGP 是面向低显存、低内存设备的视频生成整合工具。它的核心特点是让消费级显卡也能跑大模型：

· 显存要求低：官方最低 6GB 显存即可运行，社区有 8GB RTX 2080 Super 成功跑通 H3 的案例 · 内存自适应：内置多档 RAM/VRAM 配置 Profile，64GB 内存可以彻底消除 offload 带宽瓶颈 · 低显存优化：针对消费级 GPU 优化了模型加载和卸载策略，避免显存溢出导致的速度骤降 · 加速组件集成：内置 Triton、SageAttention、Lightx2v、GGuf 等加速内核，开箱即用 · 模型自动下载：首次生成时自动拉取配套模型，省去手动管理文件的麻烦

  1. 安装方式

WanGP 提供三种安装路径：

· Pinokio 一键安装：图形化应用商店，自动化程度最高 · 官方一键脚本：scripts/install.sh，自动管理虚拟环境并安装加速组件（Triton、Sage、Flash、GGuf、Lightx2v、Nunchaku） · 手动克隆安装：可控性最强，但需要手动处理依赖

本文采用官方一键脚本安装，因为都用 Linux 系统了所以你应该对命令行比较熟悉吧？

前提：确保网络可达 GitHub 和 HuggingFace，或配置代理。脚本会拉取大量依赖和模型文件，网络不通会导致安装中断。

  1. 一键脚本安装（Ubuntu）

4.1 克隆仓库

git clone https://github.com/deepbeepmeep/Wan2GP.git
cd Wan2GP

4.2 运行安装脚本

bash scripts/install.sh

脚本会自动完成：

· 选择包管理器（conda/venv） · 创建虚拟环境 · 安装 PyTorch（根据 GPU 架构自动匹配 CUDA 版本） · 安装针对你配置的最优加速内核（Triton、SageAttention 等）

核心逻辑：一键脚本把手动步骤封装了，克隆仓库这一步无法跳过，因为脚本本身就在仓库里，网络畅通是唯一需要保证的条件。

  1. 首次启动与测试

5.1 启动

cd ~/Wan2GP
source env_venv/bin/activate
export HF_ENDPOINT=https://hf-mirror.com
python wgp.py

export HF_ENDPOINT=https://hf-mirror.com作用：把现在跑的程序的”下载源”从 HuggingFace 官网换成国内镜像 hf-mirror.com，这样下模型才快得起来。这样你就会发现，你只管选择模型，剩下的Wan2GP 会自动帮你下载模型和依赖包，非常简单。

5.2 选择模型与配置

模型名称核心功能关键能力/限制对你的用途
MiniMax H3 FL2VA首尾帧模式：文生视频、首帧/尾帧/首尾帧生视频接受 0-2 张关键帧图片；原生画质最好，输出最稳主力文生视频模型，做普通视频或让单张图动起来，优先用它
MiniMax H3 Ref2VA全模态参考模式：人物/场景/动作/音色复用接受最多 9 图+3 视频+3 音频；基础画质低于 FL2VA，但功能最全短剧角色一致性、视频动作迁移（跳舞）、跟歌对口型
Viggle-Animate视频角色替换：把新角色”换”进驱动视频里基于 Ref2VA 微调；驱动视频提供动作和背景，一张参考图提供新角色；4 步极速生成想让”另一个人”跳你手头视频里的舞，用它比 Ref2VA 更直接
ControlNet-Union结构控制：姿态/深度/边缘约束视频生成附加在 FL2VA 主模型上；支持 Canny/Depth/HED/MLSD/Pose 五种控制；也能做局部重绘需要精确复刻某个动作或结构、但不想用 Ref2VA 时

一句话记：FL2VA 管画质，Ref2VA 管融合，Viggle 管换人，ControlNet 管结构。

这里我们先选择FL2VA 进行测试，下载 20B 模型即可，正常适合 12G 显存。

在界面顶部模型下拉菜单中选择 MiniMax H3。根据 3060 12G 的实际能力，首次测试建议：

· 分辨率：480P 或 832×480 · 时长：5 秒 · Profile：保持默认 Profile 4（LowRAM_LowVRAM）

5.3 自动下载与手动兜底

点击生成后，WanGP 会自动下载配套模型到指定目录。若网络中断，需手动下载：

文件 目标目录 H3 主模型 (safetensors) Wan2GP/ ckpts/ LoRA (含 fl2v 后缀) Wan2GP/loras/wan/ 或 loras_i2v/

下载完成后完全重启 WanGP，触发重新扫描。

5.4 首次测试验证

生成一个 480P/5秒 低分辨率视频。若成功输出，标志模型文件已完整就位，后续可进入常规操作。

如果，你们正常的生成视频，以我当前的配置需要五分钟左右就可以生成五秒的视频了。那么恭喜你啊，你已经部署成功了！

6.关键参数备忘

参数 建议值 说明

  • Profile 4（默认） 显存不足时用，速度慢但稳定
  • 步数（无 LoRA） 20 原生基线
  • 步数（4step LoRA） 4-6 加速预览；>6 收益停止
  • 分辨率 1280×736 3060 12G 的“甜点档”
  • 时长 5s / 10s / 15s 帧数遵循 17n+5 规则（如 243 帧≈10s）
