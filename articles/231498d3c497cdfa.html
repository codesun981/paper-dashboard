Upgrade notes

中文

本版本移除 legacy Compose：compose 主智能体、内置 workflow 及全部 compose:* 技能不再提供，复杂任务请改用 build 模式下的 /compose-next（clarify → spec → implement → verify → review → finish）。MCP 工具默认懒加载，按需发现并在就绪后调用。npm i @mimo-ai/cli 目前仅包含启动器，完整体验建议使用原生安装脚本。实验性 Orchestrator 模式已移除；Claude 会话导入与 agent-CLI 技能（claude-code / codex / grok-build）需通过环境变量显式启用。

English

Legacy Compose is retired in this release. The old compose agent, its built-in workflow, and the whole compose:* skill set are gone — for non-trivial work, switch to /compose-next on the build agent (clarify → spec → implement → verify → review → finish). On the MCP side, tools now load lazily instead of dumping the full catalog up front; they are discovered on demand and become callable once ready. Install-wise, npm i @mimo-ai/cli is only a thin launcher now, so the native installer remains the recommended path. Also worth knowing: the experimental Orchestrator mode is gone, and both Claude Code session import and the agent-CLI skills (claude-code / codex / grok-build) are opt-in via env flags.
