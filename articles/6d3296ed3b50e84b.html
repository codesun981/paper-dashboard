本期 Java 新闻汇总主要包括：关于预编译（ahead-of-time compilation）与结构化并发（structured concurrency）的新 JEP，Jakarta CDI 5.0 与 ADK for Kotlin 1.0 的 GA 发布，2026 年 9 月版 Open Liberty，TornadoVM 与 RefactorFirst 的小版本发布，Micronaut 的维护性发布，以及 Groovy 6.0 与 Gradle 9.8 的首个发布候选版本。

OpenJDK

JEP 544，预先代码编译（Ahead-of-Time Code Compilation），已经从 JEP Draft 8335368 状态提升为 Candidate 状态。该 JEP 计划在 HotSpot JVM 启动时通过优化后的原生代码提升应用的启动与预热时间，使应用能更快达到并维持峰值性能。

JEP 543，结构化并发（Structured Concurrency），已经从 JEP Draft 8389757 提升为 Candidate 状态。该 JEP 计划在经历了在 JDK 21 至 JDK 27 的七轮预览以及在 JDK 19 和 JDK 20 的两轮孵化后定稿，目前该 JEP 没有任何改动。该特性通过引入结构化并发来简化并发编程，将在不同线程中运行的相关任务组视为单一工作单元，从而简化错误处理与取消操作、提高可靠性并增强可观测性。

JDK 27

JDK 27 早期访问构建版本的Build 35发布。有关此发行的更多细节请参见发行说明。

JDK 28

JDK 28 早期访问构建版本的Build 15发布，包含来自 Build 14 的更新，修复了若干问题。更多细节见发行说明。

对于JDK 28和JDK 27，鼓励开发者通过Java Bug Database报告漏洞。

TornadoVM

在 6.0 版本发布约一周后，TornadoVM的 6.1.0 版本发布，带来缺陷修复以及对宿主每次操作固定成本的改进：当内容相同时，跳过上传每次启动时生成的 24 字节的内核参数内核栈帧（kernel-argument kernel stack-frame）；当未入队任何内容时，则跳过流同步。更多细节见发行说明。InfoQ 将跟进 6.0.0 版本的详细报道。

Jakarta EE

在每周的Hashtag Jakarta EE博客中，Eclipse 基金会的 Jakarta EE 开发倡导者Ivar Grimstad对 Jakarta EE 12 提供了更新：

Jakarta Contexts and Dependency Injection (CDI) 5.0 本周已被规范委员会批准，成为面向 Jakarta EE 12 的第一个规范。对于 Jakarta EE 12 而言，这是一个重要里程碑，因为 CDI 是平台上最核心的规范之一。更多规范将随后发布。

Starter for Jakarta EE的设计已经刷新，以与Jakarta EE网站的设计保持一致。鼓励开发者试用该新 UI 并提供反馈。

在 2025 年 11 月初批准创建的Jakarta Agentic AI 1.0规范近期发布了 M1 版本并上线了新的项目网站。2026年8月版的Azul Payara成为该规范的首个实现。

Spring Framework

Spring Tools 5.4.0发布，提供了缺陷修复、对 Eclipse IDE 2026-09 的依赖升级以及若干新特性，例如，新增验证检查和快速修复，将组合使用的@Controller与@ResponseBody注解替换为@RestController，采纳 Spring Modulith 的@ApplicationModuleListener注解，以及启用 Claude Code 插件以渲染项目的逻辑结构。更多细节见发行说明。

Open Liberty

Open Liberty 26.0.0.9GA版本发布，提供了缺陷修复、多个 CVE 的修复以及若干重要变更，例如，将 MCP Server 功能（mcp-1.0）从实验性提升为 GA，实现了OAuth 2.0 Protected Resource Metadata (RFC 9728) 规范，允许开发者在使用 OpenID Connect Client（openidConnectClient-1.0）时启用受保护的资源元数据。

此次发布带来不兼容变更，MCP Server 功能名从mcpServer-1.0更改为mcp-1.0，同时server.xml中的配置元素从更改为。

Micronaut

Micronaut 基金会发布了 Micronaut Framework 5.1.5 和 5.1.4 版本（发布新闻分别参见此处与此处），它们分别基于 Micronaut Core 5.1.15 与 5.1.14。主要变更包括：Micronaut Data 的补丁更新，修复三项 CVE，以及将 Netty 升级到 4.2.18.Final 以解决若干 CVE。更多细节见版本5.1.5与5.1.4的发行说明。

Apache Groovy

Apache Groovy 6.0.0 的第一个发布候选版本提供了缺陷修复、依赖升级与新特性，例如，新增的@GroovyABI注解，用于标记可直接从字节码调用的方法作为 Groovy ABI 的一部分；改进JsonSlurper类，新增了maxNumberLength属性，当数值标记长度超出该值时抛出JsonException，以及改进的XmlNodePrinter类以处理更大的文档。更多细节见发行说明。

RefactorFirst

Improving 的首席软件顾问Jim Bethancourt发布了RefactorFirst 0.10.0，该工具用于优先识别应用中应该进行重构的部分。此版本提供了缺陷修复与两项新特性，分别是将 JDK 17 设为最低的 Java 版本，以及支持 Kotlin 源码文件处理，使含有 Java 与 Kotlin 源码的代码库被视为统一代码库。更多细节见发行说明。

ADK for Kotlin

谷歌发布了ADK for Kotlin 1.0，这是一个用于在 Kotlin 与 Android 中构建生产就绪 AI 智能体的开发工具包。该版本实现了“通过惯用的 Kotlin API 为 Kotlin、Java 与 Android 开发者提供与 ADK 1.0 Core 的完全对等功能，并新增面向 Android 的设备端扩展，以便在 JVM 或设备端构建智能体”。该版本的新特性包括，新增MultiAgentLoader类，用于按名称提供固定集合的智能体以补充SingleAgentLoader类，以及在AdkServerConfig类中新增的流式builder()方法，允许 Java 开发者在无需全参数数据类构造函数的情况下配置服务器。更多细节见发行说明。

Gradle

Gradle 9.8.0第一个候选版本发布，提供了新特性，例如，在 Gradle daemon 与 Java 工具链中支持即将发布的 Java 27，通过简单标志支持复用 Maven 的镜像仓库设置，以及在 Windows 上提升了 45%的性能。更多细节见发行说明。
