赛博菩萨 Cloudflare 刚刚发布了一款新的命令行工具 cf，专门为 AI Agent 设计，可以通过命令行直接操作 Cloudflare 的 3000+ 个 API。@Appinn

相比主要面向开发者、只覆盖部分产品能力的 Wrangler，cf 几乎覆盖了整个 Cloudflare API，让 Codex、Claude Code 等 AI Agent 可以直接管理域名、DNS、Workers、R2 等 Cloudflare 服务。

与 Wrangler 有什么不同

Cloudflare 此前已经有成熟的命令行工具 Wrangler，但它主要面向人类开发者，只覆盖部分 Cloudflare 功能。而 cf 直接映射整个 Cloudflare API，Agent 不需要学习数千个不同的命令，就能通过统一的命令行方式查找并调用 3000+ 个 API 操作，管理几乎所有 Cloudflare 服务。

Agent 已经快占一半了

Cloudflare 为什么要专门为 AI Agent 再做一个命令行工具？

一个很有意思的数据是：今年 3 月，AI Agent 只占 Wrangler 使用量的 25%；到了最近一周，这个数字已经增长到了 48%。

换句话说，Cloudflare 的命令行工具，现在已经有将近一半是 AI Agent 在用了。
