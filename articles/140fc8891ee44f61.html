这个项目最初只是出于好玩：我的 Pi 究竟能不能在手机上跑？结果它发展成为了一个通用的 Android Agent 脚手架，一键安装，Codex, Claude Code, Pi 都可以在上面运行。

它受到了 DSH Go 与 Orca 的启发，前者带来实际的原生本地 agent 和 phone use 可能性的思路，后者提供 Pi 要怎么跑的方向。最后决定采用了 PRoot + Agent Orchestrator 的架构。

最简单来说，它做的就是两件事：

  • 让 agent 跑在本地手机环境
  • 让 agent 能控制手机

和那些只能跑在服务器上远程连接桌面端的「手机 agent」不同，它真正跑在手机本地环境上，并且可以读取手机文件、操作屏幕、运行 Unix 命令与工具。

未来它可能会支持一些别的功能，比如让 Orca 和 Paseo 在上面运行，真正实现在手机上跑 agent team。

目前在快速迭代中，欢迎试用反馈。
