Meta的Muse带火了Personal AI Agent，6天AppStore下载超90万，22天超340万，下载和日活都超过同期ChatGPT。这波浪潮席卷国内，腾讯布局较早，目前至少有4个团队在往这个方向发力。

Meta 的 Muse，带火了 Personal AI Agent（个人智能体）。

Muse 6 天 AppStore下载超过90 万，22 天超过340 万。

下载和日活，都超过同期 ChatGPT 冷启动数据。

Muse，被称作Personal AI Agent 的 iPhone 时刻。

Muse 不是技术侧的突破，而是应用侧的创新。

Muse 在产品特点上，主要表现为以下几个层面：

1）围绕个人，自主办事，关键节点由人确认

2）拥有独立云端虚拟机（云电脑），后台 24 小时持续运行

3）链接你生活里的各种日常服务

4）长期记忆，长周期任务跟进

5）安全做到安全可控，用户愿授权

但是这些技术，自动化操作、虚拟机、长期记忆、长周期任务、安全机制等，其实都是通用技术。

就像苹果手机的各种配件和配置，都不是最厉害的，但组合在一起，就是超级体验。

Muse 为何出圈，就在于，它真的能帮你办事，真的能让你少操心。

这个浪潮，很快就席卷到了国内。

各大厂纷纷下场，布局 Personal AI Agent，要打造国内版的 Muse。

在Personal AI Agent这浪潮里。

腾讯目前看，是布局比较早，走得比较激进的。

腾讯本身，擅长的就是做具体场景下的应用。

从不严格的意义上来说，腾讯目前至少有 4 个团队在往 Personal AI Agent 方向上发力。

要做腾讯版的 Muse。

1 微信小微，最有潜力的 Muse

Personal Agent 能帮人办事前提，是要链接用户日常使用的各项网络应用服务。

通过授权给 Agent，让 Agent 代劳。

Muse 最链接的基础的服务是邮箱和日历，因为漂亮国那边，习惯使用邮箱和日历，服务对接有通用的标准。

生活服务、工作各项等信息，都沉淀在邮箱、日历里。

回到国内，用户的日常服务分散在各处。

点外卖、打车、购物、酒店、通讯、教育、医疗、娱乐、支付、理财等，分散不同 app，不同服务中。

这就决定了，国内做Personal Agent，比国外有更高门槛。

而微信，经过十几年的积累，已建成覆盖几乎所有服务领域的小程序生态。

各类生活服务，都能通过小程序解决。

而小程序开发者，又能一键授权接入微信AI 能力，供微信 AI 助手小微调用。

微信小微，是天然的个人服务连接器。

加上生活服务中的基建支付，有微信支付支撑。

这也是为何，个人 AI 智能体Muse 让 Meta 股价大涨，也让原本没有关系的腾讯大涨的原因。

背后是因为微信的生态，和小微智能链接微信服务的能力。

微信小微目前仍在内测中，也没有提供独立的独立的云端虚拟。

但技术层面的问题是好解决的，壁垒是链接服务的能力。

Muse 原本就就是依赖 Facebook、WhatsAPP、Instagram渠道分发的。

小微，土生土长在微信里。

已开放就是全民覆盖。

微信小微，一旦提供 Personal Agent 服务。

将会最接近 Muse 产品形态的产品，也是最有潜力的 Muse 。

2、LightVela，最懂用户的 Muse

LightVela，是腾讯最早的、最成熟的 Personal Agent。

LightVela 产品早在今年 4 月就已公测上线，7 月正式上线。

支持用户常见个人 Agent，每个 Agent 在云端托管，开辟单独的云端环境。

支持用户自定义 Agent 管理长期记忆、用户画像和长对话上下文。

支持给你的 Agent 添加人设。

可直接通过微信、QQ、钉钉、飞书等聊天软件，给 Agent 在任务。

运行在 LightVela 上的 Agent 不依赖你的电脑，长期在线运行。

数据存储到你的专属服务器。

这些，都很接近 Muse 的形态。

LightVela，比 Muse 早 2 个月上线。

LightVela 这个产品的出发点，是来源早期龙虾热是，团队大量的线下装机实践。

以及后来 Hermes Agent 的出现，和团队的持续跟进。

LightVela 团队了解到，用户需要的不是 Claw 的安装，Agent 的搭建。

而是需要一个低门槛、持续、稳定、省事、越用越懂你的 AI 助手。

LightVela 就是基于这个对用户的理解，推出来的个人 云端 Agent 服务。

将 AI Agent 的完整能力搬上云端，7×24 小时待命，数据完全归你。

LightVela，是腾讯中最懂用户的 Muse。

3、TX Handy Bot，最神秘的 Muse

TX Handy Bot，服务号上，明确定义：Your Personal AI Agent。

Handy，是方便的、便捷的意思；Bot，是机器人、智能体意思。

HandyBot ，是要做你省事省心的Agent。

logo，为两个人对话，一个是人，一个是 Agent。

通过对话的方式，让 Agent 完成事务处理。

但是目前， 该服务号，已注销。

可能产品还不成熟，或者不想过早披露出来。

这是腾讯，最神秘的 Muse。

4 元宝个人Agent，最想证明自己的 Muse

据字母榜消息，元宝也正在筹备推出 Persona Agent。

是在元宝上新增模块，还是推出单独的个人智能体？

产品形态和推出时间，还未正式确定。

但是，元宝是有这个基础的。

模型自不必说，并且个人智能体核心，比拼的也不是模型能力。

比拼的是服务能力，服务的宽度和深度，是不是真正做到让人省心。

三分靠模型，七分靠应用吧。

元宝做通用型 AI 助手，已积累了丰富的能力。

也提供了多项围绕个人生活服务方面的功能，比如个人计划、金融理财、外卖、购物、旅游、饮食助手等。

如果开放接入腾讯生态中的各项生活服务。

或是比较有竞争力的 Personal Agent。

在2024-2025 年通用 AI 助手的时代，元宝被给予重望，花重金推广。

因为没有不可替代的使用场景。

红包短期效果显著，长期效果拉跨，结果不尽如人意。

一直背负着这个失利到现在，现在仍被各大媒体谈及。

如今，如果元宝团队做Personal Agent。

这是个好机会，正名的好机会。

元宝 Personal Agent，是最想证明自己的 Muse

5、Cue，和腾讯有点关系的Muse

Manus 最新上线的 Cue，是实打实的、原生的 Personal AI Agent。

对标的就是 Meta 的 Manus。

这个产品，原本和腾讯没有什么关系。

但前阵子，腾讯牵头国内资本，以约 20亿美元估值，从Meta手中回购Manus相关股权。

腾讯将成为最大单一外部股东，创始团队仍掌握实际控制权。

虽然不控股，不属于腾讯系。

但是最大单一外部股东的身份，让腾讯和 Manus的多方合作成为可能。

这不算腾讯系的Muse，但和腾讯关系密切。

2026 年，是Agent 战场最激烈的一年。

，所有公司入局虾场，全民养虾。2026 开局的上半场，是龙虾狂热期

目前，已退场。这场竞赛中，没有赢家，或者说所有人成了赢家，龙虾为 Agent 的到来铺路。

，各大厂和模型公司激战 AI 办公。2026 年中场，是办公 AI Agent 的战争

WorkBuddy 目前暂时性胜出，但战争远远没有结束，各方还在激战中。

，这是被Muse 验证有巨大用户需求但是没有跑通盈利早期阶段。2026 下半场，来到了个人 AI Agent

的预计接下来的几个月，各大厂、模型公司、创业团队都会为之疯狂。

上半场龙虾，中场 AI 办公，下半场个人 Agent。

2026 年的 AI 应用落地，真的很忙，很卷，很有意思。

中秋国庆之际，腾讯、字节、阿里都在大力压局 Personal AI Agent ，暗中发力。

国庆节后，会更热闹。

而腾讯，最擅长的就是落地场景、落地应用。

在新掀起 Personal AI Agent 浪潮下，我感觉这次腾讯没有掉队。
