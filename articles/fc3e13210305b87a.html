作为 0.2.1 系列的首个候选版本，本版本汇总了自 v0.2.0-rc.2 以来的主要用户和开发者相关变更。

新增功能

  • 允许用户从“自定义插件索引源”中发现和安装插件。 @turtle1999
  • 插件管理页新增「让 Agent 创建插件」入口，可保留草稿进入创造模式；发送需求后才开始执行。 @ZiyaZhang
  • 支持插件启用、停用、卸载及更新后的依赖同步；启用热重载时，更新或重新安装的可替换插件直接生效，无法热重载时提示重启。 @imccyu, @turtle1999
  • 可选插件支持极简模式，Official 插件列表支持按需安装与当前发布版对应的 Claude Code 和 Codex 组合包，并可用于 headless、SDK 和 ACP profile。 @tianyicui, @turtle2099
  • 新增实验性插件的 Session 状态记录接口，供插件写入和读取自己的会话记录。 @tianyicui
  • 新增实验性 Claude Code Mods 兼容层。目前阶段的主要目的是验证 Claude Code Mods API 功能大致为 DeepSeek Harness 插件的一个子集，而非为用户提供实际的完整兼容性。 @tianyicui
  • 新增实验性开发者工具组合包，提供会话原始日志、聊天分组与正文的双向定位，以及内嵌 NodeJS 调试工具；内嵌 DevTools 目前使用英文界面。 @imccyu, @turtle2099
  • 新增实验性思考过程机器翻译插件，可在插件页启用，选择 Bing、Google 或付费 DeepSeek Flash。 @tianyicui, @ZiyaZhang, @imccyu
  • 新增实验性 Git Worktrees 插件，可在插件页启用，由 Agent 创建并进入独立的 Git checkout。 @tianyicui, @turtle2099
  • 自定义模型 API 支持通过UI中配置各模型的推理等级，无需手动修改配置文件。 @LegGasai
  • pi-ai 路由支持按模型能力处理会话中的系统提示词更新，以及工具的动态新增和移除。 @Tuyixiang
  • 极简模式支持读取图片和自动压缩长对话，Web 与桌面端可通过 /compact 指令手动压缩上下文。 @LogosVeritas
  • 全局指令支持读取共享 agents 目录中的 AGENTS.md，可通过 DSH_AGENTS_HOME 指定目录。 @tianyicui
  • 新增 working_directory 工具，并为 TypeScript/Python SDK 提供会话工作目录的读取和切换接口。 @tianyicui
  • SSH 新增独立可执行的 helper 运行时，支持远端文件操作、进程、终端、沙箱和 Node PTC。 @LegGasai
  • Web 版支持在本机 HTTP 访问时登录 DeepSeek 账号。 @lsdsjy
  • 支持识别已发送消息中的密钥和令牌，并默认脱敏按需查看。 @ZiyaZhang
  • 新会话支持预填未发送的提示；恢复草稿或切换工作区时保留文件、目录和会话引用。 @imccyu
  • 新增工作步骤收起时机设置，可选择回答结束后收起，或在下一条普通消息到来时收起。 @imccyu
  • Markdown 文件预览将 YAML 头部元数据显示为清晰的字段列表。 @turtle2099

其他变更

  • API Key 读取优先级变更：Web端/桌面端优先采用已保存的凭据；headless 默认改用环境变量和 .env，不读取已保存的密钥。 @Magolor
  • 移除运行时 invariant 插件及各包的 ./invariant 导出；使用这些诊断入口的开发者需相应调整扩展或自定义 profile。 @turtle2099
  • 子路径插件不再读取独立的 package.json，显示文本和图标须通过对应子路径导出；插件开发模板同步补齐本地化信息与图标。 @turtle1999
  • 第三方插件的版本兼容性优先按 engines.dsh 判断；未声明时沿用原有规则。插件作者需检查声明是否覆盖支持的 DSH 版本。 @turtle1999
  • 输入区统计扩展拆为 activity 和 usage 两个独立入口；覆盖旧 stats 整行的插件需要更新注册 ID。 @turtle1999
  • 为用户消息、文本与图片展示、新会话页及模型选择器添加扩展位，支持插件定制对应内容。 @imccyu, @LegGasai
  • 自动化任务改为 Web 内置能力，提醒工具按模式提供：标准、创造和 PTC 模式可用，极简模式和子代理不可用；旧实验组合包选择会自动清理，已有任务保留。 @Chinesezjc, @turtle1999
  • 关闭计划审阅以补充修改意见时，直接结束当前轮次并等待用户反馈，避免额外调用模型。 @turtle2099
  • 统一子代理执行与完成通知，工具立即返回 child ID；自定义 SDK runtime 需支持 session/wait。 @Dudu-0223
  • Agent Team 消息改为直接投递目标 Inbox，移除独立 outbox、自动重试和重发去重；相关配置与结果字段需迁移。 @Dudu-0223
  • Python PTC 接入 Session 文件沙箱策略；自定义组合需提供 sandbox 和 sandboxPolicy 服务。 @tianyicui
  • 移除工具展示的 both 混合模式，仅保留 native 和 ptc；使用旧模式的配置与 API 调用需要更新。 @tianyicui
  • 移除 agent-instructions 插件逐行 dshHome 配置，指令目录改从进程的 DSH_HOME 或默认目录读取。 @tianyicui
  • 默认 SDK profile 从固定的编程 Agent 改为通用 AI Agent 身份，适用于一般任务。 @Dudu-0223
  • 使用 --from-default-profile 重建已有自定义配置时，会替换该配置及其插件和设置。 @turtle2099
  • TypeScript 和 Python SDK 支持 resume 功能，恢复已保存的会话，继续使用原有会话 ID 和工作目录。 @koalazf99
  • Python SDK 的 Office 引擎和完整创作环境改为按需下载。 @yudshj
  • 完善网关授权与连接机制，支持按调用方身份控制资源访问，并独立管理 API 连接及其交互参与方式。 @imccyu
  • Web 支持通过 --public-url 指定显示、打开及提供给模型的对外访问地址，支持带路径前缀的反向代理入口。 @oraluben
  • Web 支持绑定指定的 IPv4/IPv6 地址，并通过 --tls-cert 和 --tls-key 配置原生 HTTPS 监听。 @oraluben
  • pi-ai 更新至 1.0.2，包含上游模型目录更新和适配器修复。 @tianyicui
  • 更新第三方模型支持；Azure 提供方名称统一为 azure，使用旧名称 azure-openai-responses 的提供方配置需迁移。 @LegGasai
  • 更新运行时工具、MCP 协议、图片处理和客户端渲染依赖，纳入兼容版本的安全修复。 @tianyicui

This first release candidate for 0.2.1 summarizes the major user- and developer-facing changes since v0.2.0-rc.2.

New Features

  • Discover and install plugins from custom plugin index sources. by @turtle1999
  • Add a “Let Agent create a plugin” entry to plugin management. It opens Creator mode while preserving the draft and starts work only after the request is sent. by @ZiyaZhang
  • Support dependency synchronization when plugins are enabled, disabled, uninstalled, or updated. With hot reload enabled, replaceable plugins take effect directly after an update or reinstallation; changes that cannot be hot-reloaded request a restart. by @imccyu, @turtle1999
  • Support optional plugins in Minimal mode. The Official plugin catalog offers on-demand installation of Claude Code and Codex bundles matching the current release, for use in headless, SDK, and ACP profiles. by @tianyicui, @turtle2099
  • Add Session state-record APIs for experimental plugins to write and read their own session records. by @tianyicui
  • Add an experimental Claude Code Mods compatibility layer. At this stage, the main goal is to verify that the Claude Code Mods API's capabilities are broadly a subset of what DeepSeek Harness plugins can do, rather than to offer users complete, practical compatibility. by @tianyicui
  • Add an experimental Developer Tools bundle with raw session logs, bidirectional navigation between chat groups and the conversation, and embedded NodeJS debugging tools. The embedded DevTools currently uses an English interface. by @imccyu, @turtle2099
  • Add an experimental reasoning translation plugin, enabled from the Plugins page with Bing, Google, or paid DeepSeek Flash as the provider. by @tianyicui, @ZiyaZhang, @imccyu
  • Add an experimental Git Worktrees plugin that can be enabled on the Plugins page for Agents to create and enter separate Git checkouts. by @tianyicui, @turtle2099
  • Configure reasoning levels for individual custom API models in the UI without editing configuration files manually. by @LegGasai
  • Support in-conversation system prompt updates and dynamic tool additions and removals on pi-ai routes according to model capabilities. by @Tuyixiang
  • Minimal mode can read images and automatically compact long conversations. Web and Desktop users can run the /compact command to compact context manually. by @LogosVeritas
  • Load global instructions from AGENTS.md in the shared agents directory, with DSH_AGENTS_HOME available to select its location. by @tianyicui
  • Add the working_directory tool and TypeScript/Python SDK APIs for reading and changing a session’s working directory. by @tianyicui
  • Add standalone executable SSH helper runtimes supporting remote file operations, processes, terminals, sandboxing, and Node PTC. by @LegGasai
  • The Web app supports DeepSeek account sign-in when accessed over local HTTP. by @lsdsjy
  • Detect keys and tokens in sent messages and mask them by default, with an option to reveal them. by @ZiyaZhang
  • Support unsent initial prompts for new sessions and preserve file, folder, and session references when restoring drafts or moving them between workspaces. by @imccyu
  • Add a setting to collapse work details either when the response finishes or when the next regular message arrives. by @imccyu
  • Display YAML frontmatter as a readable field list in Markdown file previews. by @turtle2099
