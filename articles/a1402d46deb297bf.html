IT之家 11 月 13 日消息，微软 Microsoft 365 遭遇了近年来最严重的服务故障之一，Exchange Online、Outlook、SharePoint 及部分 Teams 服务中断近一天半。今天早些时候，微软一名高管为此次故障致歉，并对事态表示遗憾，基本承认短时间内无法解决问题。

Anthropic 将自身部分服务的故障归咎于 Microsoft 365 连接，并通过 Claude Status 页面陆续发布了以下通报：

  • 调查中： 我们正在调查 Microsoft 365 连接器错误率升高、响应缓慢的问题。用户通过连接器访问邮件、SharePoint、Teams 聊天和日历时可能遇到请求失败，新用户也可能无法完成连接。我们会尽快通报调查进展。

  • 已查明： 问题出在上游服务提供商，导致 Microsoft 365 连接器受到影响。邮件、日历和搜索功能的大多数请求均无法正常处理，新建连接也可能失败。我们正与服务提供商沟通，并将尽快通报进展。

  • 更新： 我们仍在与上游服务提供商合作处理故障。Microsoft 365 连接器的邮件、日历和搜索功能大部分请求仍无法正常处理。Claude for Outlook 也受到波及，用户可能无法执行邮件和日历操作，部分用户甚至无法打开加载项。我们将在一小时内再次更新。

……

然而，Claude 遭遇了新的服务故障。据IT之家今天早些时候报道，Anthropic 确认，claude.ai、Claude Code 和 platform.claude.com 均出现错误率异常升高的情况，用户无法在这些平台完成身份验证。
