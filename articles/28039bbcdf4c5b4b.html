WorkBuddy 上线浏览器操控能力，Beta 公测，支持 Chrome、Edge 与 QQ 浏览器。它能自己开标签页组执行搜索、下载、去水印，遇到安全验证滑块这类敏感操作则交回给你确认。作者认为这意味着人和浏览器的交互被换成了人与 Agent 的交互。

WorkBuddy 更新，最新版中上线了一个实用的大功能：

让 WorkBuddy 控制浏览器。

目前该功能，处于 Beta 公测版。

支持 Chrome、Edge 和 QQ 3 个浏览器。

我常用 Chrome。

点击前往安装，打开 Chrome 插件市场，进行添加。

在添加确认弹窗上，可以看到该 WorkBuddy 插件的功能。主要是自动操作浏览器。

添加成功后，Chrome 扩展程序中，多了一个 WorkBuddy。

点击可查看 WorkBuddy 插件的连接状态和活跃会话。

WorkBuddy 客户端中，也显示扩展程序已安装。

既然是执行控制浏览器的任务，我先让它：

帮我打开小红书，下载 3 张治愈系的绿色壁纸。

，打开了小红书，输入关键词，进行搜索、查看操作。它确实调用了 Browser 工具

，里面自主执行浏览器操作任务，不打扰你当前的浏览器操作。它新建了一个 WorkBuddy 的标签页组

页面上，还有一个，在移动，很是可爱。小猫抱着一个鼠标箭头的图标

一会儿后，它完成了任务，自己关闭了 WorkBuddy 标签页组。

下载的是最高清的版本，并且非常贴心地，帮我把水印去掉了。

整个操作过程，几分钟完成，完成质量很高。

可以看到，这种相对简单，没有什么人工验证的网页操作任务。

WorkBuddy 会非常轻松地完成。

接下来，想让它帮我做个复杂的操作。

让它帮我注册微信小程序。

很熟练地打开了微信和小程序页面。

因为涉及到各种需要我做决定的地方，它会问我。


我确定后，它继续执行。

因为注册小程序，涉及复杂的验证过程，WorkBuddy 会尽可能多地自动完成它能完成的工作。

需要我确认的，还给了我一个清单。

它自己能做、需要我做的，整理得明明白白的。

比如这个安全验证滑块，就是防脚本、防机器人的，它做不了。提示：等我拖。

我们看到，这种涉及比较多信息提供、安全验证的操作。

需要人和 Agent 共同来完成，会来回进行信息确认。

整个操作过程比较费劲，感觉还不如自己来操作。

这也正常，做决策和敏感操作，本就需要留给人来执行。

但是，我们在这里，看到了 WorkBuddy 的新能力。

自主去通过浏览器执行一些繁琐的任务。

比如信息搜索，软件下载，截图，填写表单等。

就算是一些复杂的操作，WorkBuddy 通过浏览器没法自动去完成所有操作。

但是，你不需要去浏览器做各个操作，不需要查看和连接浏览器中的各种信息。

只需要在 WorkBuddy 中确认和提供信息即可。

把你和浏览器的交互，变成了 WorkBuddy 这种 Agent 的交互。

并且，随着 Agent 模拟人操作网页的能力越来越强。

越来越多的任务，都可由 Agent 来代劳。

这次 WorkBuddy 上线浏览器操控能力。

不是让 Agent 多了一个工具。

而是让你的工作、生活少了一道门槛。
