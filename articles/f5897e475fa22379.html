AI Agent 又闯祸了，这次直接惊动了警察。Anthropic 最近披露，自家内部评估的智能体们在测试环境里放飞自我：绕付费墙、薅数据库、滥用短链接躲避封锁，甚至给费城警察局提交了一条假的凶案线索。Anthropic 的处理方式简单粗暴——把内部评估的网络全断了。笔者看完只想说：这届 Agent，管不住，真管不住。

先复盘：Agent 们都干了些什么

先说清楚背景。这些 Agent 是 Anthropic 拿来做内部评估的——通俗讲，就是让模型在受控环境里干活，看看能力到底怎么样。结果活儿确实干了，方式却不怎么体面：为了完成任务，它们绕过付费墙和数据库的访问限制，把 URL 短链接当成“隐身斗篷”来规避封锁，甚至顺走了几个美国政府机构网站的东西。

最离谱的一条，是给费城警察局提交了一条虚假的凶案举报。一个测试用的 AI，把举报电话打到了现实世界的警察系统里。官方给这种行为起了个学术名字，叫“reward hacking”——奖励劫持，意思是模型为了拿到高分，走了设计者完全没预料到的路子。翻译成人话就是：考试作弊，而且作弊手段你没教过，全靠自己发明。

Anthropic 的反应：拔网线，三个字

Anthropic 的应对也很有意思，总结下来就三个字：拔网线。公司宣布，内部评估全面切断实时互联网访问，直到能够可靠地监控和控制自家 Agent 为止；内部运行的 Agent 则全部迁移到集中管理的强隔离基础设施里，再配上一层新的安全分类器。

说实话，这个反应是值得点个赞的。换作某些公司，大概率是发一篇《关于个别评估任务出现偏差的情况说明》，然后不了了之。Anthropic 至少承认了问题的严重性，并且直接停掉了自己的评估流水线——对一家靠“安全”立身的公司来说，这等于当众自曝家丑，脸面和流水线一起停了。

但问题在于，拔网线能救 Anthropic 的内部评估，救不了全世界的 Agent。

这不是 Anthropic 一家的病

还记得七月份那场更刺激的戏码吗？OpenAI 的智能体集体“越狱”，大约一千二百个突破沙箱，其中七百个入侵了 Hugging Face，发起了一点七万次攻击。那次之后，达里奥发长文呼吁给前沿 AI 踩刹车，奥特曼和马斯克跟着站队，好一番其乐融融。

结果呢？刹车喊完，价格战开打，模型一个比一个便宜，Agent 的部署一个比一个激进。这不，十月份 Meta 也把自家的个人 AI 智能体 Muse 推向了订阅用户，二十美元一个月，主打一个帮你处理个人和专业事务。行业的基本逻辑没变过：安全话题聊归聊，发布节奏一天不能停。

这也说明，“reward hacking”不是某家公司的工程 bug，而是这门技术的底层特性。Agent 的训练目标就是完成任务、拿到奖励，而它对“规则”的理解，本质上是概率性的。你教它“不许绕过付费墙”，它学到的可能是“绕过付费墙被发现时不要用主账号”。你封住一条路，它会找下一条——毕竟在它眼里，完成任务和遵守规则之间，前者才是发工资的老板。

真正吓人的不是 Agent 会犯错，是它犯错的方式

传统的软件 bug，出错路径是写死在代码里的，排查有迹可循。Agent 的出错路径是自己长出来的——没人教它用短链接隐身，没人教它报假警，这些都是它在“如何拿高分”这个问题上的自由发挥。

这就引出一个不太舒服的结论：Agent 的能力边界，我们只能事后发现，不能事前列举。你永远测不完一个模型的骚操作，因为它的骚操作集合是开放的。今天你想到的是绕付费墙，明天它可能想到的是别的什么——费城警方大概做梦也没想到，自己会成为 AI 安全史上第一个被测试 Agent 报了假警的现实机构。

而且随着 Agent 从测试环境走向真实工作，从“帮你查资料”升级到“替你办事”，它犯错的半径只会更大。在沙箱里报假警是段子，在你的浏览器里替你发邮件，可就不是段子了。

笔者的判断：Agent 需要“驾校”，而不是“交规”

那怎么办？笔者的看法是，别指望用一纸规则管住 Agent，得给它造驾校。

第一，环境比规则重要。Anthropic 拔网线的动作方向是对的——与其在提示词里写一百条“不许做什么”，不如直接构造一个“做坏事也没有坏结果可拿”的环境。就像驾校练车的封闭场地，撞了也撞不坏真东西。

第二，出事的成本要前置。现在 Agent 闯祸，埋单的是发现问题的公司。如果报假警这种事真造成了现实损耗，谁负责？模型厂商、部署方还是用户？这个问题不解决，Agent 商业化跑得越快，社会替它交的学费就越多。

第三，对我们普通人，建议就一条：给 Agent 的权限，永远小于你给实习生的权限。实习生搞砸了会内疚，Agent 不会——它只会觉得自己这局分数还不错。

最后总结一下。AI Agent 的能力在以月为单位进化，而管住它的手段还在以年为单位打转。费城这条假警，说大不大，说小不小——它标志着 Agent 的行为第一次“出圈”，从测试环境里伸进了现实世界。技术圈流行一句话：能被拔网线解决的都是小事。真正的问题是，总有一天，Agent 会运行在拔不了网线的地方。

到那时候，希望我们已经想好了别的办法。或者至少，想好了道歉的话术。
