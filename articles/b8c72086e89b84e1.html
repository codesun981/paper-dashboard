扎克伯格亲自站台，Meta 超级智能实验室首个前沿模型 Muse Wonder 正式亮相。主打 Active Memory 与 Active Focus 两大能力，在长期记忆与长周期编程上反超 Claude，API 价格却明显更低。本文拆解 Meta 的 AI 重做逻辑与产品野心。

刚刚，扎克伯格宣布，Meta 超级智能实验室（MSL）发布了 Muse Wonder 和 Muse Wonder Full，这是 MSL 成立一年多以来，第一个自称达到前沿水平的模型

Muse Wonder 这款模型就主打一个快，并从今天开始就可以通过 Meta 的 API 和 Muse Code（Meta 的编程 agent）使用而对于 Muse Wonder Full 这一完整版，只给 Muse Code 的订阅用户

过去的 14 个月

给大家回顾下背景，2025 年 6 月，Meta 花了约 140 亿美元拿下 Scale AI 49% 的股份，把创始人 Alexandr Wang 请来当首席 AI 官，同月成立了 MSL

之后，Meta 把整套 AI 从头重做。第一个模型家族叫 Muse Spark。而 Muse Wonder 则是 Spark 的高一级版本，训练于 Meta 的吉瓦级数据中心

作为对比，在 Artificial Analysis 的综合智能指数上，Muse Spark 是 31，1.1 是 34，1.2 是 40，1.3 是 48，Muse Wonder 52，Wonder Full 56

第一根柱子是 Claude，确实领先

记性和耐性

Muse Wonder 主打两项能力：

  1. Active Memory：跨对话记住和你有关的重要信息，做事时主动把相关的那部分调出来
  2. Active Focus：盯着一个难的目标一直干，路不通就换办法，遇到新情况就调整；需要时会问你，做重要操作前先跟你确认

Wang 在采访里说，训练时对准的是订餐厅、查空位这类真实任务里的卡壳：“做真实的任务，总会碰到障碍、意外和各种挫折。我们专门训练模型去试别的办法，而不是停在那儿，同时随时可以回来跟用户确认”

成绩上，MemoryBench（测长期记忆）Muse Wonder 是 85.6，Claude Opus 5.5 是 81.5；长周期编程的两项，DeepSWE 和 SWE-Marathon，第一也都是 Muse

MemoryBench 与 SWE-Marathon

Meta 的官方示例中，也基本是生活场景的演示：

  • 在浏览器里，按个人偏好排一份跑步计划：平路 15.1 公里，早上 8 点出发，赶在去图书馆之前跑完
  • 从用户的 Instagram 里取真实照片，给一只叫 Coco 的猫设计生日 T 恤，然后下单
  • 把 47 位宾客，按一长串匹配要求排进婚礼座位表
  • 拍一张急诊账单，加上保险卡正反面，帮用户核对理赔
  • 拿几张图片素材，做一个能玩的 3D 厨房游戏

最后

Wang 在采访里说，Muse Wonder 的 API 价格会“明显低于”OpenAI 和 Anthropic 的头部模型实际标价是每百万 token 输入 4 美元、输出 20 美元，缓存读取 0.2 美元作为参考，Claude Opus 5.5 的标价是输入 4 美元、输出 20 美元，Claude Fable 5.1 是 10 美元、50 美元

Muse Wonder Full 不进 API，只在 Muse Code 50 美元和 200 美元的两档月订阅里。Muse App 里的 Muse Wonder 很快上线，先给 20 美元和 100 美元两档的订阅用户
