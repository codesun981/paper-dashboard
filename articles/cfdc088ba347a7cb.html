[更新日志] Firefox 157 发布：「多年来最大规模的视觉焕新」

RC-pulish • 2026-09-30 09:44 •浏览器•阅读 32

Mozilla 于当地时间 2026 年 9 月 29 日首次向正式版渠道用户发布了版本为 157.0 的 Firefox 浏览器。本文列出了该版本的更新日志。

更新点

  • ，浏览器工具栏、侧边栏、菜单及各功能均采用现代化外观，基于我们更新后的设计系统打造。此外还包括： Firefox 多年来最大规模的视觉焕新现已推出
    • 新的内置主题，提供浅色和深色版本，一键即可个性化 Firefox 的外观。
    • 新的紧凑模式，可缩小工具栏和标签页间距，为网页内容留出更多空间，适用于较小屏幕和分屏布局。
  • WebRTC 视频通话现在可以在支持的设备上使用硬件 AV1 解码，而不再始终通过软件解码 AV1 视频。
  • 现在，当 Firefox 设置为记录其加密密钥时，它会在站点信息面板（地址栏中的盾牌图标）和设置中显示警告，因为这可能会让计算机上的其他软件读取加密的网络流量。
  • Firefox Suggest 现已在奥地利、比利时、捷克共和国、丹麦、芬兰、匈牙利、爱尔兰、卢森堡、荷兰、挪威、波兰、葡萄牙、斯洛伐克、西班牙、瑞典和瑞士的地址栏中提供建议。这些建议可在 Firefox Suggest 设置中进行控制。

修复

  • 修复了来自手机和平板的视频在 WebRTC 通话中横向或倒置显示的问题。
  • 修复了页面仍在加载时（例如 Firefox 刚启动后不久），地址栏搜索所输入文本而非打开所选建议的问题。
  • 修复了某些以 8 位色彩格式编码的 HDR 视频在 Windows 上显示暗淡发灰而非以 HDR 显示的问题。
  • 改进了反复更改视频播放速度（例如在 YouTube 上）时的音频和视频同步。
  • 修复了全屏模式下光标移动到屏幕边缘时垂直标签页侧边栏不再出现的问题。
  • 修复了 Windows 上使视频全屏后 Windows 任务栏仍显示在视频上方的问题。
  • 。多项安全修复

变更

  • 按下 Tab 键现在会直接将焦点移至地址栏和搜索栏的文本输入框，而不再先停在搜索引擎按钮上。仍可通过 Shift+Tab 访问该按钮。
  • Amazon 不再作为内置搜索引擎包含在内。仍可在搜索设置中将其添加为自定义搜索引擎。
  • 更新后的侧边栏现已向所有人启用。仍在使用旧版侧边栏的用户将保留类似布局，面板切换器位于侧边栏顶部。此外，“显示侧边栏” 选项已从设置中移除。
  • 在我们继续完善新设计期间，仍可通过在 about：config 中将 sidebar.revamp 设置为 false 来恢复旧版侧边栏。这也会关闭垂直标签页。该首选项将保留至 2027 年底。
  • 网页 alert（）、 confirm（）和 prompt（）对话框、颜色和日期选择器以及表单自动完成下拉菜单现在会匹配页面的浅色或深色配色方案。
