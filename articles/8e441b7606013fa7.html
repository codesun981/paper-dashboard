优秀项目

  • 项目地址：skill-zoo (opens new window)
  • 项目说明：一个基于 Tauri 和 React 开发的本地 AI 技能管理工具，能够浏览、安装和更新来自 GitHub 的技能包，支持 Claude Code、Cursor 等多种 AI 编码工具，旨在统一管理 AI 技能，支持 macOS 和 Windows 平台使用。
  • 项目地址：CoPet (opens new window)
  • 项目说明：一个基于 Tauri 与 React 开发的桌面伴侣工具，能够实时响应多种 AI 代理的操作状态，旨在为开发者增添趣味与陪伴，支持 macOS 和 Windows 平台。
  • 项目地址：renewlet (opens new window)
  • 项目说明：一个基于 React 和 Go/PocketBase 构建的自托管订阅追踪工具，能够管理周期性续费、发送时区感知提醒，支持多通知渠道与预算分析，可在 Docker 或 Cloudflare Workers 上运行。
