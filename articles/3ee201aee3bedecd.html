简介

本版本移除了一些过时的策略，减少针对特定模型的行为改变：上下文与输出上限、推理档位改从 models.dev 和用户配置读取，不再按模型名推断，也不再默认发送 temperature / top_p；/variants 可在配置中直接按档位名启用，子 agent 继承父会话的档位；GPT 模型也不再自动开启 Codex 风格的提示词和工具集，所有模型默认使用同一套（需要时可设置 MIMOCODE_CODEX_MODE=true）。

此外，内置联网搜索改为通过 MIMOCODE_ENABLE_EXA=1 启用（也可接入搜索 MCP）；小米 API key 与 Token Plan key 可同时登录；记忆搜索支持中文子串召回；并修复了额度耗尽仍重试、压缩失败残留等稳定性问题。

Highlights

This release removes some outdated policies and reduces model-specific behavior changes: context/output limits and reasoning levels now come from models.dev and your config rather than model-name heuristics, and temperature/top_p are no longer sent by default; reasoning levels for /variants can be enabled by name in config, and subagents inherit the parent session's level; GPT models also no longer switch to a Codex-like prompt and toolset automatically — every model uses the same defaults (set MIMOCODE_CODEX_MODE=true to opt in).

Also: built-in web search is now opt-in via MIMOCODE_ENABLE_EXA=1 (or add a search MCP server), Xiaomi API and Token Plan keys can be signed in together, memory search recalls Chinese substrings, and reliability fixes cover retries on exhausted quota and leftovers from failed compactions.
